# Sebelum Uber Menjemput: illustration kit

Original artwork drawn for this photobooth. No third-party stock or ephemera packs were used, so there is nothing to license.

| File | Use |
| --- | --- |
| raven.svg | Strip header motif, attract screen |
| moth.svg | Strip header motif, page corners |
| crescent-moon.svg | Strip header motif, night scenes |
| pumpkin.svg | The one orange accent, review screen |
| candle.svg | Background flicker loop, print screen |
| wax-seal.svg | Buttons, strip footer seal (SUM monogram) |
| gift-tag.svg | QR card on the final screen (place the QR inside the dashed box) |
| frame-corner.svg | Live preview frame; rotate 90° for each corner |
| lace-border.svg | Strip header and screen tops; tiles every 40 px |
| torn-edge.svg | Deckled paper edge; flip vertically for the opposite side |
| parchment-texture.png | Page and strip background, 1200 × 1600 |

Palette: raven ink #1B1A1F, ash #4A4744, parchment #E9DFC9, ivory #F5EFE3, pumpkin ember #C8742B, tarnished gold #A88A4E, rose wax #8E2C2C.

Text inside wax-seal.svg and gift-tag.svg uses generic `serif` and `monospace`; set them to the app's display and typewriter fonts (Cormorant Garamond, Special Elite) in the build.
